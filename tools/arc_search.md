# Arc Search

Arc Search is the mobile app from The Browser Company that took the radical position: maybe you don't want to "go to a website" at all. The "Browse for me" feature reads multiple websites for you and produces a single bespoke web page summarising what you wanted to know. For mobile search where every tap costs something, the workflow is materially better than Google.

## What it actually is

An iOS and Android app. Looks like a search box; behaves like a search engine for the first second; then reveals "Browse for me" which spawns an agent that reads multiple sources and writes you a synthesised web page. The synthesised page is real HTML, with links to each source.

## Setup

1. Download from the App Store or Google Play. Free.
2. Open. Type a query. The default behaviour is normal search.
3. Tap "Browse for me" instead of "Search the web." The agent runs (~10 to 20 seconds).
4. Read the synthesised page. Click into any source for the full original.

## How I use it day to day

* **Honest:** I've used Arc Search on iPhone for a few months as my mobile default for non navigational queries.
* **"What's the difference between X and Y" queries.** Arc Search reads the comparisons across blogs and produces a clean summary. Faster than tapping through three SEO articles.
* **Travel research on the go.** "What are the best neighborhoods to stay in Lisbon for a 3 day trip." The synthesised page is structured, cited, useful.
* **Quick factual lookups** with sources. Arc Search shows where the facts came from; click through if I want depth.
* **Comparison shopping.** "Best portable monitor 2026 for travel." Arc Search reads reviews; produces a comparison; saves time.
* **The page format is the unique idea.** Not a list of blue links; not a long chat answer; an actual web page tailored to what I asked.

## Gotchas

* It's mobile only. Desktop browsing has different ergonomics; The Browser Company addresses that with [dia.md](dia.md).
* Privacy: the agent visits multiple sites on your behalf. Read the privacy policy.
* For navigational queries (find a specific URL), regular search is better. Arc Search shines on research questions.
* The "Browse for me" agent occasionally produces summaries with errors. Click the citations for important claims.
* Free; no paid tier as of April 2026. The Browser Company's monetization may shift.
