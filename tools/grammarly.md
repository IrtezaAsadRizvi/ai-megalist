# Grammarly

Grammarly is the AI writing aid most people forgot was AI. Decades of grammar / spelling / style heuristics, then the LLM era added GenAI features (rewrite, generate, tone match) without changing the core promise: text everywhere gets quietly better. The breadth (every text field on every device) is what made it ubiquitous; the GenAI layer kept it relevant.

## What it actually is

A grammar and writing assistant available as browser extension, desktop app (macOS, Windows), iOS / Android keyboards, and direct integrations with Word, Google Docs, Outlook, Slack, Notion. The new GenAI features (Grammarly Generative AI) add prompt based generation and rewriting alongside the original spell / grammar / style checks.

## Setup

1. Sign up at [grammarly.com](https://www.grammarly.com).
2. Free tier: spelling, grammar, basic suggestions.
3. Pricing: Premium $12/mo, Business $15/seat/mo, Enterprise.
4. Install:
   * Browser extension (Chrome, Safari, Firefox).
   * Desktop app for macOS / Windows.
   * iOS / Android keyboard for mobile.
   * Microsoft Word / Outlook add ins.
5. Grammarly suggestions appear inline as you type, in any supported app.

## How I use it day to day

* **Spelling and grammar everywhere.** This is the original value; still the most reliable feature. Quietly catches typos in Slack, Gmail, LinkedIn.
* **Tone match.** Set a tone preference (Professional, Friendly, Confident); Grammarly nudges your phrasing. Useful for cross context writing (boss email vs friend DM).
* **GenAI rewrite.** Highlight text → "rewrite this for clarity" / "make it shorter." Comparable to Wordtune's flow; baked into Grammarly.
* **Generate.** Prompt to generate text directly in any field. Quality is fine for routine emails; for serious writing, Claude / ChatGPT are stronger.
* **Style guide compliance.** Business tier lets teams enforce style guides (vocabulary, banned phrases, brand voice) across all writing.

## Gotchas

* Grammarly's native suggestions are conservative. For more interesting rewrites, prompt with intent.
* The browser extension can be heavy; some users disable on specific sites.
* Premium upsells inside the product are persistent. Free tier is enough for spelling / grammar; the GenAI features are paid.
* Privacy: Grammarly sees what you type. They have policies; review them. Some employers prohibit Grammarly on work systems.
* Conflicts with native spell check or other tools (Wordtune, Hemingway) sometimes happen. Pick one for any given workflow.
