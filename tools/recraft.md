# Recraft

Recraft is the AI image tool that takes brand consistency seriously. Where Midjourney optimises for the most beautiful image and Ideogram for legible text, Recraft optimises for *vector output, repeatable styles, and brand kits*. If you're a designer or a brand team, this is the tool that fits the workflow rather than fighting it.

## What it actually is

A web based AI image platform with vector and raster generation, custom style training, brand kit support, and one of the better text rendering engines. Their proprietary model (Recraft v3) does both raster photoreal and clean vector output (SVG), which is rare in the field.

## Setup

1. Go to [recraft.ai](https://www.recraft.ai), sign up.
2. Free tier: 50 credits/day.
3. Pricing: Basic $10/mo (1000 credits), Advanced $25/mo (3000), Pro $48/mo (4500), Enterprise.
4. Pick a model — Recraft v3 (most powerful) or Recraft 20B (faster).
5. (Optional) Create a Style: upload reference images, train a custom style. Use it across all generations to keep brand consistency.

## How I use it day to day

* **Vector illustrations.** Generate a custom illustration in vector format; download SVG; drop into Figma, edit cleanly. The output is real vector with editable paths, not auto traced raster.
* **Brand consistent generation.** Train a custom Style on existing brand assets; every new generation respects the visual language.
* **Logos.** Recraft is one of the few tools where AI generated logos are actually usable as starting points. Vector means they scale.
* **Icon sets.** "Generate 12 line icons in this consistent style for a fintech app." The custom Style feature makes the output cohesive.
* **Image text combinations** for posters, social cards. Recraft's text rendering is on par with Ideogram.

## Gotchas

* The vector output is genuinely vector but not always clean. Complex shapes can have unnecessary points; budget time to clean up in Illustrator / Figma.
* Custom Styles need decent reference images (10+) and care in selection. Garbage in, garbage out.
* Pricing is competitive but credits for vector generation are higher than raster. Watch usage.
* For pure photoreal aesthetic without text or vector concerns, Midjourney still wins.
* The web UI has accumulated features fast; navigation is busier than Ideogram or Midjourney's clean editors.
