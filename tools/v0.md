# v0

v0 is what I use when I already have a Next.js codebase and I want a beautiful component, fast. It's the only "prompt to UI" tool that produces output I'd actually paste into production without a heavy rewrite, and that's because Vercel built it specifically for the React + Tailwind + shadcn/ui stack everyone in their ecosystem already runs.

## What it actually is

Vercel's UI generator. You describe a component (or a full page); v0 produces React + Tailwind + shadcn/ui code, with a live preview. Newer versions can scaffold full Next.js applications, but the sweet spot is still "give me one polished component."

## Setup

1. Go to [v0.dev](https://v0.dev), sign in with Vercel/GitHub.
2. Free tier gives ~10 credits/day; Premium is $20/mo for 200 credits.
3. Type a prompt: "A pricing table with three tiers, monthly/yearly toggle, dark mode, accessible."
4. v0 generates 2 to 4 candidates. Pick one, refine in chat ("Make the middle tier featured," "Add a free trial CTA").
5. Copy the code, or use the "Open in v0" CLI: `npx v0@latest add <component-id>`.

## How I use it day to day

* **Marketing pages.** Hero, features, pricing, FAQ — v0 nails the genre on the first try ~70% of the time.
* **Forms.** "A multi step checkout form with validation." The shadcn/ui foundation means form components come with accessibility built in.
* **Dashboards.** Tables, charts, sidebars. Less polished than full app builders but enough for a competent first pass.
* **Iterating in chat.** Describe a tweak, v0 regenerates only what's needed. The diff is visible.
* **Refining locally.** I copy the code into Cursor, then make Cursor pretty up the rest of the app to match the style.

## Gotchas

* v0 assumes Next.js, Tailwind, and shadcn/ui. If your stack is different (Vue, Svelte, plain CSS), the generated code is less useful. There is some cross stack support but it lags.
* The credit system is generous on Pro and miserly on free. Don't evaluate seriously on the free tier.
* Generated code occasionally references components that don't exist in your shadcn install. Run `npx shadcn-ui@latest add <component>` to fill the gaps.
* No real backend logic. v0 is UI only; pair with Lovable, Bolt, or your own backend.
* Multi page generation (full app mode) is impressive but the output is harder to maintain than the single component flow. Prefer one component at a time.
