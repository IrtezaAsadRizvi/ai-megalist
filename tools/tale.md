# Tale: shared project tasks for people and AI agents

Tale is a self-hosted workspace for teams that want human and AI-agent work on the same project task board, alongside project files and knowledge. Its task workflow is documented around explicit starts and reviewable reports and files.

## What it actually is

An MIT-licensed Community application with shared project tasks, files, knowledge, and configurable project agents. A task can be assigned to a person or an agent. Assigning it to an agent does not start work: a person starts the run, then reviews its reports and deliverables.

## Setup

Use the [official self-hosting guide](https://docs.tale.dev/self-hosted/install/quickstart) to deploy Tale, configure the required services and a model provider, and create a project. Follow the [project-agent guide](https://docs.tale.dev/platform/projects/project-agents) to choose an agent runtime and model, then use the [task workflow](https://docs.tale.dev/platform/projects/task-automation) to start and review work.

## Pricing

Community software is free under the MIT license. Hosting, supporting infrastructure, and model usage have separate costs. Optional Enterprise operation and support are separate offerings; see [Tale's pricing page](https://tale.dev/pricing).

## Where it fits day to day

- Keeping tasks assigned to people and agents visible in one project.
- Sharing project files and knowledge as context for work.
- Reviewing agent reports and resulting files before accepting the work.

## Gotchas

- Self-hosting involves operating the application and its dependencies; a free software license does not mean free infrastructure or model calls.
- Assigning an agent to a task is not an automatic start. The start and review steps are explicit.
- This entry describes the project's documented capabilities. It is not an independent hands-on review or a benchmark of output quality.
