# Kagi

Kagi is the paid, ad free search engine for people who decided that ad supported search has gotten too noisy. The AI features (Quick Answer, FastGPT, Universal Summarizer, the Assistant) are baked in; the underlying search is independent (uses its own index plus partner APIs). For knowledge workers willing to pay for search, Kagi is the most polished option.

## What it actually is

A subscription web search engine. Pricing: Starter $5/mo (300 searches), Professional $10/mo (unlimited), Ultimate $25/mo (unlimited + Assistant access to GPT‑5.5 / Claude / etc.). Available as a web app, browser extensions, and a default search engine setting. The "Universal Summarizer" summarises any URL or YouTube video; "FastGPT" is a fast cited AI search; the Kagi Assistant is a chat with the model of your choice.

## Setup

1. Go to [kagi.com](https://kagi.com), sign up.
2. Free trial gives 100 searches.
3. Subscribe; install browser extensions for Chrome / Safari / Firefox to use Kagi as default search.
4. (Optional) Configure Lenses (custom search profiles e.g. "academic only," "no SEO content") at kagi.com/settings.

## How I use it day to day

* **Honest:** I've trialed Kagi multiple times; it's a real upgrade for search if you stick with it. I currently use a mix of Google, Perplexity, and DuckDuckGo for free.
* **Quick Answer** at the top of every search. Cited summary, often saves the click through.
* **Universal Summarizer** for any URL. Paste a long article, get a summary. Decent on text; on YouTube it's useful for "should I watch this."
* **FastGPT** for cited AI search. Comparable to Perplexity's free tier; sub second responses.
* **Kagi Assistant (Ultimate).** Chat with Claude / GPT / Gemini, with optional web search grounding. The model picker is the differentiator.
* **Lenses.** "Show me only academic results" or "exclude listicle sites" — applied to every search globally.

## Gotchas

* The pricing puts a real bar in front of "should I switch." Most users default to free; Kagi is for the minority who feel the cost of bad search.
* The index is smaller than Google's. For long tail queries (very obscure topics), Google sometimes finds things Kagi doesn't.
* Some features (Assistant, Universal Summarizer) are only on the Ultimate tier; Professional is "search only."
* The browser extension is the canonical way; remembering to use kagi.com manually is friction.
* Privacy is real but check the policy; Kagi makes specific commitments and they're worth reading.
