# ComfyUI

ComfyUI is the node graph editor that the AI image and video community converged on. The first time you see a ComfyUI workflow it looks like a circuit diagram exploded; after a week, every other image generation UI feels like a toy. If you want full control over the diffusion pipeline — multiple models, ControlNets, LoRAs, custom samplers — ComfyUI is where you live.

## What it actually is

An open source desktop app and web server for running diffusion models with a node based workflow editor. Each generation is a graph: load model → encode prompt → KSampler → VAE decode → save image. You wire up the boxes; the engine runs the graph.

Supports Stable Diffusion (1.5, 2, XL, 3.5), FLUX, Hunyuan, video models (Mochi, LTX, Wan), upscalers, ControlNets, IP Adapters, animation, audio. As of 2026, ComfyUI is the de facto standard for serious local image and video work.

## Setup

1. Easy path: download the desktop app from [comfy.org](https://www.comfy.org). Drag to Applications.
2. On first launch, ComfyUI offers to download a default model (SDXL or SD 3.5). About 6 GB.
3. Open. The default workflow loads — text → image, single sampler.
4. Drag any image generated by ComfyUI back into the canvas to load its workflow. This is a major workflow.

### Manual install (Linux / power users)
1. `git clone https://github.com/comfyanonymous/ComfyUI && cd ComfyUI`
2. `pip install -r requirements.txt`
3. Download models into `models/checkpoints/`, LoRAs into `models/loras/`, ControlNets into `models/controlnet/`.
4. `python main.py`. Open `localhost:8188`.

### ComfyUI Manager
Install [Manager](https://github.com/Comfy-Org/ComfyUI-Manager) — the unofficial app store for community nodes. You will need it.

## How I use it day to day

* **Workflow templates from generated images.** Find an image with a workflow you like; drag it into ComfyUI; the entire pipeline loads. Faster than building from scratch.
* **Multi step pipelines.** Generate base image → upscale → inpaint specific regions → refine → output. All as one graph; one click runs the entire flow.
* **LoRA stacking.** Load 3 LoRAs at different weights (style + character + lighting). Hard in other UIs; trivial in ComfyUI.
* **ControlNet for layout.** Pose, depth, line art, segmentation — all available as conditioning inputs to the sampler.
* **Custom nodes for new techniques.** Every research paper that lands in image / video gets a ComfyUI node within a week. The ecosystem is the moat.

## Gotchas

* The learning curve is steep. Plan a weekend to get fluent.
* Memory is the constraint. Big graphs with multiple models OOM on consumer GPUs. Use VRAM offload nodes; quantize models.
* Custom nodes can break with updates. ComfyUI Manager helps but pin versions for production.
* Headless / API mode exists but is less documented than the UI. Reading the source is sometimes the answer.
* The community's NSFW content is non trivial; civitai.com mirrors many workflows. Default to caution.
