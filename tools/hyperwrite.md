# HyperWrite

HyperWrite is the writing assistant that quietly turned into a personal agent. It started as a "rewrite this paragraph" Chrome extension and now runs a browser agent (Personal Assistant) that can do flight bookings, email triage, and form filling. The writing tools still work fine; the agent is the more interesting half of the product.

## What it actually is

OthersideAI's writing and personal agent product. Browser extension plus standalone web app. Includes a long form generator, rewrite tools, autowrite Chrome integration, and a "Personal Assistant" agent that can browse and act on the web on your behalf. Free tier; paid plans unlock heavier usage and the agent.

## Setup

1. Sign up at [hyperwriteai.com](https://www.hyperwriteai.com) with Google or email.
2. Install the Chrome extension if you want inline rewriting in Gmail, LinkedIn, etc.
3. (Optional) Subscribe for the Personal Assistant agent (paid tier).
4. (Optional) Set up agent flows: "Find flights under $400 from X to Y on this date." Watch the run; intervene when needed.

## How I use it day to day

* **Inline rewrites in webmail.** The Chrome extension's "rewrite for tone" is faster than copying into ChatGPT for one liners.
* **Long form drafting.** Briefs, blog drafts. Output is competent but unremarkable; I prefer Claude or ChatGPT for anything I'll publish.
* **Agent for tedious web tasks.** When I need to compare flight prices across three sites or fill out a long signup form, watching the agent do it is satisfying. Reliability is mid; expect to babysit.

The product I'd recommend depends on what you want. For pure writing, Claude or ChatGPT are better. For "an agent that lives in my browser," HyperWrite is one of the few mature options outside ChatGPT Operator.

## Gotchas

* Agent reliability lags ChatGPT Operator and Claude Computer Use. Expect failed runs on complex flows.
* The product surface is broad; quality varies feature by feature. The autowrite extension is solid; some of the templated tools feel dated.
* Privacy: agent runs see logged in sessions in your browser. Be careful what you expose.
* Pricing has changed several times. Check the current plans before subscribing.
