# Tool guides

Per tool setup and usage notes for the [megalist](../README.md). Each file is a short, opinionated walkthrough: what the tool actually is, how to set it up in five minutes, what I use it for day to day, where it bites.

The voice borrows from Karpathy: first person, hedged where I'm guessing, specific where I have numbers. If a guide doesn't sound grounded, the tool likely sits in the long tail of "I read the docs, I haven't shipped with it." Treat those with appropriate skepticism.

## What's missing

This is a sample. The full megalist names ~200 tools across 22 categories; only ~10% have a guide here so far. Open a PR if you want to add one - keep the structure consistent (hook, what it is, setup, daily use, gotchas, pointers).

## File naming convention

Underscores, lowercase, no hyphens. Example: `claude_code.md`, not `claude-code.md`.
